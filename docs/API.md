接口文档（最终版）
=========

> **说明**：
> 
> * 所有接口统一使用 JSON 格式，字符集 UTF-8。
> 
> * 除注册/登录外，其他接口需在 Header 中携带 `Authorization: Bearer <token>`。
> 
> * 枚举值（如 `type`）暂不强制统一，文档中给出推荐示例，联调时可协商微调。
> 
> * 批量删除的 `ids` 参数为逗号分隔字符串，如 `1,2,3`。
> 
> * 分页参数统一为 `page`（从1开始）、`size`（默认10）。
> 
> * 排序参数 `sort` 可选 `time_desc`（默认）或 `time_asc`。
> 
> * 时间格式统一使用 `YYYY-MM-DD`（如 `2025-04-11`）。

一、认证模块
------

| 接口   | 方法   | 路径              | 请求参数                                                                   | 响应格式                                                 |
| ---- | ---- | --------------- | ---------------------------------------------------------------------- | ---------------------------------------------------- |
| 用户注册 | POST | `/api/register` | `{ "username": "string", "password": "string", "nickname": "string" }` | `{"code":200, "data":null}`                          |
| 用户登录 | POST | `/api/login`    | `{ "username": "string", "password": "string" }`                       | `{"code":200, "data":{"token":"jwt", "user":{...}}}` |

二、供需模块
------

| 接口     | 方法     | 路径                          | 请求参数                                                                                                                                                                                              | 响应格式                                             |
| ------ | ------ | --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| 获取所有供需 | GET    | `/api/posts`                | 无                                                                                                                                                                                                 | `{"code":200, "data":{"total":n, "list":[...]}}` |
| 发布供需   | POST   | `/api/posts`                | `{ "title": "string(必选)", "content": "string(可选)", "type": "string(必选，推荐 supply/demand)", "area": "string(必选)", "price": "string(必选)", "contact": "string(必选)", "images": "string(可选，多个用逗号分隔)" }` | `{"code":200, "data":null}`                      |
| 删除单个供需 | DELETE | `/api/posts/{id}`           | 路径参数 `id`                                                                                                                                                                                         | `{"code":200, "data":null}`                      |
| 批量删除供需 | DELETE | `/api/posts?ids=`           | 查询参数 `ids`（如 `1,2,3`）                                                                                                                                                                             | `{"code":200, "data":null}`                      |
| 我的发布列表 | GET    | `/api/posts/user/publishes` | 无（token获取userId）                                                                                                                                                                                  | `{"code":200, "data":{"total":n, "list":[...]}}` |
| 搜索供需   | GET    | `/api/posts/search`         | `title`(可选), `content`(可选), `type`(可选), `sort`(可选, time_desc/time_asc), `page`(可选, 默认1), `size`(可选, 默认10)                                                                                         | 同获取所有供需                                          |

补充约定
----

* **错误码**：建议使用 HTTP 状态码，或统一在响应体中增加 `code` 字段（200成功，其他为错误）。

* **空值处理**：可选字段如果不传，后端应能处理为 `NULL` 或默认值，不报错。

* **枚举灵活性**：如 `type` 字段，前端可传 `supply`/`demand` 或中文，联调时与后端协商一致即可，文档不作强制。

* **图片URL**：上传接口返回相对路径（如 `/upload/xxx.jpg`），前端需要拼接部署的基础地址（如 `http://localhost:8080`）。
